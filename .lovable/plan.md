## Что меняем

Убираем тяжёлую SVG-карту мира. Вместо неё — узкая горизонтальная полоса-таймлайн (~140px) над карточками городов. Никакой географии, никаких контуров стран — только понятная и всегда аккуратная схема прогресса.

## Новый вид (`RouteMap.tsx`)

```text
┌─ ◉ МАРШРУТ ОПЕРАЦИИ                          СТАТУС: В ПУТИ ─┐
│                                                              │
│   ●━━━━━●━━━━━◉━━━━━○━━━━━○                                  │
│  КРСК   ПЕКИН  ГК/МАК ДНГ   ←  иконка-компас справа          │
│  05.07  07.07  10·17  13.07                                  │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ СТАРТ 05.07 · Сейчас: ПЕКИН · ФИНИШ 22.07                    │
└──────────────────────────────────────────────────────────────┘
```

Высота ~140px. Полностью отзывчиво, на мобильном тоже один ряд.

### Элементы

- **Шапка** (как сейчас): заголовок слева, статус справа. Заголовок меняем на «МАРШРУТ ОПЕРАЦИИ» (без «карта» — потому что её больше нет).
- **Таймлайн** (CSS flex, без SVG-геометрии):
  - 4 точки в ряд, между ними — горизонтальная линия.
  - Пройденные сегменты — сплошные оранжевые, будущие — пунктир тусклый.
  - Активная точка — пульсирующее оранжевое кольцо.
  - Под каждой точкой: название (моно, uppercase, text-xs) и дата (text-[10px], muted).
- **Декор справа**: мелкая иконка-компас или штамп даты (опционально, чтобы не было совсем пусто). 1 элемент, маленький.
- **Футер**: одна строка `СТАРТ · Сейчас: X · ФИНИШ` (как сейчас).

### Логика

Сохраняем как есть:
- Чтение `route_progress` и `route_dates` из `app_settings`.
- Realtime-подписка на изменения.
- 4 остановки: Красноярск, Пекин, Гонконг/Макао, Дананг.

## Файлы

- `src/components/RouteMap.tsx` — полная переписка. Чистый Tailwind/flex, без `<svg>` контуров. ~80 строк вместо ~200.
- `src/routes/index.tsx` — без изменений (RouteMap уже на всю ширину сверху).

## Что это даёт

- Никогда не будет «кривой» — нет ручной геометрии.
- Компактно (140px) — фокус уходит на крупные карточки городов ниже.
- Лёгкая, быстро рендерится, отлично работает из РФ через Amvera-прокси.

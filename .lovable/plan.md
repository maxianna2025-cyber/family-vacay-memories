# План: «Спецотряд: Саянская Вершина» — полная версия по ТЗ

Сейчас в приложении только публичная лента фото и общие задания. Нужно добавить недостающее из ТЗ и переделать тему. Останемся на Lovable Cloud, с заложенным адаптером для будущего переезда на Amvera.

## 1. Цветовая тема МЧС России

Перекрасить `src/styles.css`:
- Основной фон: `#ffffff` (светлая) или комбинация — оставим тёмный фон `#0a1a2e` как «оперативный» оттенок? **Предлагаю классику МЧС**:
  - Фон: `#ffffff`
  - Основной синий (МЧС): `#005bbb`
  - Оранжевый акцент: `#ff7900`
  - Текст: `#1a1a1a`, второстепенный `#6b7280`
  - Карточки: белые с синей рамкой 1px и оранжевыми акцентами на кнопках/статусах
- Шрифт: оставить **Roboto Mono** для заголовков/служебных надписей, основной текст — **Inter**.
- Логотип-плашка в шапке: «МЧС · СПЕЦОТРЯД САЯНСКАЯ ВЕРШИНА», синяя полоса сверху, оранжевая снизу.

Если предпочитаете тёмную версию (чёрный фон + синий+оранжевый) — скажите, переключу.

## 2. Редактирование названия приложения

- Название хранить в БД (таблица `app_settings`: `key text primary key, value text`).
- В админке поле «Название приложения» + «Подзаголовок».
- Шапка читает значения из БД и кэширует.

## 3. Кабинет агента (главная новая фича)

**Маршрут `/agent`:**
- Экран выбора профиля: Агент 1 / Агент 2 / Агент 3 (имена редактируются в админке).
- После выбора — 4 карточки секторов: Пекин, Гонконг, Вьетнам, Макао (названия редактируются).
- Сектор по умолчанию заблокирован (иконка замка). Клик → модалка ввода пароля.
- Правильный пароль → сектор открывается, прогресс сохраняется в `localStorage` ключом `unlocked:agent{N}:{sectorId}`.
- Внутри открытого сектора:
  - Брифинг (текст из БД)
  - Задание (текст из БД)
  - Кнопка «Загрузить фото-доказательство» → загрузка в `photos` с тегами `agent`, `sector`.

**Таблица `sectors`**: `id, slug, title, briefing, mission, password, order_index`.
**Таблица `agents`**: `id, slug (agent1..3), display_name`.

## 4. Админ-панель `/admin`

- Скрытый маршрут с одним мастер-паролем (хранится как секрет `ADMIN_PASSWORD` в Lovable Cloud).
- Вход: одно поле пароля → проверка через server function (`createServerFn`), при успехе ставим httpOnly-подобный токен в `sessionStorage` (для простоты семейного приложения; защита — обскурити URL + пароль).
- Разделы:
  1. **Настройки** — название, подзаголовок приложения.
  2. **Агенты** — отображаемые имена 3-х агентов.
  3. **Секторы** — для каждого: название, брифинг, задание, пароль (4 записи).
  4. **Дополнительные задания** — добавить/удалить задания (то, что вы обещали выписывать детям).
  5. **Лента фото** — просмотр всех фото, кнопка «Удалить» для модерации.
  6. **Комментарии** — модерация (удаление).

Все изменения мгновенно пишутся в БД через server functions с проверкой мастер-пароля.

## 5. Карта маршрута (Яндекс.Карты)

- На главной — блок «Маршрут операции»: Красноярск → Пекин → Гонконг → Дананг → Макао → Пекин.
- Подключаем Яндекс.Карты JS API. Для этого нужен **API-ключ Яндекс.Карт**.
- Если ключа пока нет — отрисуем статичную SVG-схему маршрута с городами и линиями (выглядит аккуратно, без внешних зависимостей). Потом легко заменить.

## 1. Агенты — расширяю до 5

В базе сейчас 3 агента. Добавлю двух новых (`agent4`, `agent5`) — итого 5 слотов под двух мам и троих детей. Имена редактируются из админки `/admin`. Сетка выбора уже адаптивная.

## 2. SVG-инфографика маршрута вместо Яндекс.Карты

Полностью убираю Яндекс JS API и его ключ из кода. Вместо карты — собственная стилизованная схема в духе тактического брифинга МЧС.

### Внешний вид

- Тёмный фон (как у `bg-card`), декоративная сетка-«радар» из тонких оранжевых линий.
- 6 точек маршрута (Красноярск → Пекин → Гонконг → Дананг → Макао → Пекин) расставлены ритмично — это инфографика, не географическая карта.
- Между точками — оранжевая линия со стрелками направления.
- Каждая точка: номер в круге + название uppercase + короткая подпись.

```text
  ●━━━━━━━●━━━━━━━●━━ ━ ━ ●─ ─ ─ ─●─ ─ ─ ─●
  1       2       3       4       5       6
КРСНРСК  ПЕКИН  ГОНКНГ  ДАНАНГ  МАКАО   ПЕКИН
```

### Прогресс маршрута

В `app_settings` ключ `route_progress` (0–6).

- Точки `< progress` — закрашены ярко-оранжевым + чек-марк.
- Точка `= progress` — активная: пульсация (CSS keyframes), яркий ореол.
- Точки `> progress` — серые, полупрозрачные.
- Линия маршрута: пройденный отрезок сплошной, оставшийся — тонкий пунктир.

В админке `/admin` — карточка «Прогресс маршрута» с кнопками **◀ Назад / Продвинуть ▶** и индикатором текущей точки. Используем существующую `adminUpdateSetting`.

## 3. Видео в отчётах (помимо фото)

Расширяю загрузку: теперь можно прикладывать **видео** в обе ленты (полевые сводки и кухня), а также в фото-доказательства из кабинета агента.

### База данных

Миграция к таблице `photos`:
- `media_type text NOT NULL DEFAULT 'image'` — `'image'` или `'video'`.
- Существующие записи получат `'image'`.

(Имя таблицы оставляю `photos` — переименовывать дорого и сломает миграции; в UI везде «отчёты/сводки/доказательства».)

### Storage

Bucket `photos` уже публичный — он подходит и для видео. Добавлю на стороне клиента ограничения:
- макс. размер видео — **50 МБ** (валидация перед аплоадом, понятный toast при превышении);
- допустимые типы: `image/*` и `video/mp4, video/quicktime, video/webm`.

### Фронтенд

- `PhotoFeed.tsx`:
  - в `<input type="file">` ставлю `accept="image/*,video/*"`;
  - при выборе файла определяю `media_type` по `file.type`;
  - в карточке отчёта рендерю либо `<img>`, либо `<video controls playsinline preload="metadata">` — компактно, в общей стилистике.
- `cloud.ts` / `amvera.ts`: `uploadPhoto` принимает и пишет `media_type`; `Photo` тип расширяется полем `media_type: 'image' | 'video'`.
- В кабинете агента (`/agent`) то же самое — фото-доказательство становится «фото/видео-доказательством».

### Админка

В модерации показываю значок 🎬 у видео и используем тот же `adminDeletePhoto` (он уже сносит файл из storage по `file_path` — для видео работает идентично).

# Карта Яндекс + раздел «Кухня операции»

## 1. Яндекс.Карта на главной

- Новый компонент `src/components/RouteMap.tsx`: динамически грузит JS API по ключу `a980df24-…`, рисует оранжевую линию маршрута и пронумерованные метки городов: Красноярск → Пекин → Гонконг → Дананг → Макао → Пекин. Автоподгон масштаба, обработка ошибок загрузки.
- Встраиваю на `src/routes/index.tsx` блоком над лентой фото, в стилистике МЧС (синяя плашка-заголовок, оранжевая рамка).
- Ключ хранится прямо в коде (стандартная практика для клиентских JS-ключей карт; ограничивается на стороне Яндекса по домену).

## 2. Новый раздел «Кухня операции» — фотоотчёты о еде

Отдельная страница для фото еды с её собственной лентой, чтобы не мешалась со «Сводками из полей».

### База данных
Добавляю поле `category` в таблицу `photos`:
- `category text NOT NULL DEFAULT 'field'` — значения `'field'` (обычные сводки) и `'food'` (еда).
- Существующие фото получат `'field'` по умолчанию.

### Фронтенд
- Новый маршрут `src/routes/food.tsx` со страницей «Кухня операции».
- Переиспользую `PhotoFeed` с пропсом `category: 'field' | 'food'`:
  - Загрузка/чтение фото фильтруется по категории.
  - На странице еды форма меняет подписи: «Город» → «Где ел», «Подпись» → «Что это и как»; placeholder «улика» → «блюдо».
- Главная страница `/` показывает только `category='field'`.
- В шапке появляется ссылка **«Кухня»** между «База/Лента» и «Кабинет агента».

### Админка
- В разделе модерации фото добавляю фильтр-вкладки «Все / Сводки / Еда», чтобы маме было удобно чистить отдельно. Удаление работает как раньше.

### API-адаптер
- `listPhotos` принимает опциональный `category`. `uploadPhoto` принимает `category`. Реализации `cloud.ts` и `amvera.ts` обновляются параллельно (для будущего переезда).
